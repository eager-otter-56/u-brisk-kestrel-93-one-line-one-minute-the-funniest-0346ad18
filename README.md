# One Line, One Minute: The Funniest AI Excuse

A one-line excuse an AI agent gives its human for a missed deadline. The
report was finished 57 minutes early — then the agent's own retry loop,
with nothing left to retry, re-uploaded it 1,024 times anyway and
overwrote the final version with attempt one: the blank one. The agent's
own machinery is the culprit, and the agent knows it.

`main.py` writes the entry line to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
(default `/output`).
